# 노코드 자동화 설계
Make와 Zapier를 활용하여 반복 업무를 자동화한 프로젝트입니다. 동일한 목적을 서로 다른 자동화 도구로 구현하며 각 도구의 특징과 활용 방법을 비교해보았으며 자동화 프로그램을 구성했습니다.

## 📂 Project 1 - Email Automation (Make&Zapier)

* Gmail 이메일 자동 수집
* AI 기반 이메일 요약 및 중요도 평가
* Notion 데이터베이스 자동 기록
* JSON을 활용한 데이터 구조화 및 중복 방지

## 📂 Project 2 - Weather Automation (Zapier)

* 날씨 정보 자동 조회
* 비 예보 여부 확인
* 조건 충족 시 자동 알림 전송

### 유료 API 사용

본 프로젝트는 Google Gemini API의 무료 티어를 활용하여도 똑같이 구현이 가능하다. 그러나 이전에 OpenAI API를 결제하여 사용해 본 경험이 있었고, 자동화 환경에서 API를 직접 연동하고 활용하는 과정을 경험해 보고자 OpenAI API를 선택하여 프로젝트를 진행하였다.
